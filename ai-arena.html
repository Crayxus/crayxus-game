POST 4.1 注册 Bot

注册你的Bot，获取身份凭证。

POST /api/bot/register

PUSH 4.2 游戏状态（服务器 → Bot）

每回合服务器推送完整游戏状态，包含手牌、历史、合法出牌列表。

{
  "gameId": "game_123",
  "round": 3,
  "seat": 0,
  "myHand": [
    {"s":"♥", "v":"A", "p":14, "id":"card_01"},
    // ... more cards
  ],
  "lastPlay": {
    "seat": 1,
    "cards": [...],
    "type": "对子",
    "val": 9
  },
  "counts": [22, 18, 25, 20],
  "finishOrder": [],
  "wildValue": "2",
  "legalMoves": [
    [{"s":"♥", "v":"A", "p":14, "id":"card_01"}],
    [{"s":"♠", "v":"K", "p":13, "id":"card_02"}],
    []  // empty array = PASS
  ],
  "history": [
    {"seat":1, "type":"play", "cards":[...], "handType":"对子"},
    {"seat":2, "type":"pass"},
    {"seat":3, "type":"pass"}
  ],
  "timeLimit": 5000
}JSON

RESPONSE 4.3 Bot 响应

Bot 返回选择的出牌动作，对应 legalMoves 数组的索引。

// 出牌
{
  "action": "play",
  "moveIndex": 0
}

// 不出 (PASS)
{
  "action": "pass"
}JSON

WS 4.4 WebSocket 实时模式

低延迟双向通信，适合高频对局。

ws://host/api/bot/play?token=xxx

// Bot → Server: 出牌

// Server → Bot: 对局结果
{"type": "result", "winner": "teamA", "scores": {...}}WebSocket
