ARCHITECTURE · 技术路线

为什么这样设计(经业界验证)

纯竞速里,模块化(高精定位 → 赛车线优化 → MPC/Pure Pursuit 跟踪)碾压端到端 RL(F1TENTH 基准:端到端慢约 18%;IAC/A2RL 全尺寸队伍清一色模块化)。RL 只用在超车决策 + 参数自整定。而定位精度是整件事的命门——这正是之前栽的地方。

📐

高精定位(命门)

室内 NOKOV 光学动捕(亚毫米/毫秒级,OptiTrack 备选)+ 车载 LiDAR 冗余;室外 RTK-GPS(厘米级)+ IMU + 轮速 EKF。定位准,赛车线才准。

🏁

赛车线 + 控制

离线算最优赛车线(最小曲率)→ MPC/Pure Pursuit 高频跟踪。再用 RL 做超车与参数自整定。这是 AI 跑赢人类的核心。

🔁

训练 + sim2real

仿真里 RL 练到极限 → 用真车数据做 sim-to-real 残差补偿(Swift 击败人类冠军的关键步)→ 上车。固定赛道 + 控光。

TRACK · 赛道与场地(关键决策)

定位怎么做——这是能否超人类的命门

中天是平面竞速赛道(无立体墙、室外无 GPS 精度),且你已实测 UWB / ArUco贴标 / 普通顶置摄像头全部失败(高速 + 大场地下精度/延迟/运动模糊扛不住)。审核后的最终方案——AI·GP 标准赛道 18×10 m(16×8 起步 ~ 20×12 旗舰,规格详见《一年学习路线》)。

🏠 室内定位:两档可选
  • 🅰 旗舰档 · NOKOV 光学动捕(首选,稳超人类):红外相机+反光球三角测量,≠失败的顶置摄像头,不受运动模糊/光照拖累,亚毫米精度、毫秒级延迟,高速竞速金标准。18×10 标准场 12–18 台 ≈¥28 万;16×8 起步 8–12 台 ≈¥20 万(整套 ¥20–40 万区间,多车共享)+ 车载 LiDAR 冗余。
  • 为什么选 NOKOV(度量科技,北京):国产、整套更便宜、服务响应快,标杆案例最贴合(华南理工无人机+无人车集群 40+ 目标同场追踪)。OptiTrack 作备选:已被利亚德收购,中国代理=虚拟动点(vopoint.com),无淘宝整套渠道,需走厂商报价。
  • 🅱 经济档 · 车载 LiDAR + 人造立体地标(¥1–3 万级起步):沿赛道布反光柱/矮桩给 LiDAR 特征 → 粒子滤波定位(F1TENTH 验证,cm 级)。不上动捕、不大改场地、省钱起步;精度 cm 级(vs 动捕 mm),超人类把握略低。LiDAR 车上已含,额外只是地标桩(几百元)。
  • ⚠️ 中天是平面无墙赛道:经济档必须加立体地标(纯平面 LiDAR 无特征也定不了位);旗舰档动捕不依赖赛道特征。
🏞️ 室外:RTK-GPS 基站 + 车载移动站
  • 室外无墙、GPS 米级不够 → RTK 厘米级(基站架场地、车载移动站),这是 Indy/A2RL 全尺寸 AI 赛车的标配。
  • RTK + IMU + 轮速 EKF 紧耦合:RTK 给绝对位置,IMU 在两帧间高频推算,扛住高速急转。
  • 赛道边界用锥桶 + 标线,车载摄像头/LiDAR 识别;加一个边线计圈摄像头做裁判。
  • 基站是场地基础设施、一次性、多车共享。
✖ 已排除(实测/调研否决)
  • UWB:精度 10–30cm,贴线不够(你已弃)。 ArUco/AprilTag 贴标:高速运动模糊、转弯姿态误差飙到 20°+。 普通 RGB 顶置摄像头:大场地分辨率/精度掉 + 图像处理延迟,高速糊掉。
  • 纯车载视觉端到端 RL:DeepRacer 平台限速 ~14km/h,高速"赢人类"无公开实证,不作主方案(可作长期研究)。 Vive Lighthouse:覆盖上限 ~24m² < 128m²,accuracy 仅 2-3cm,不适合。

  • 先打单圈计时赛:AI 跑线一致、零疲劳、毫秒反应,在单圈极限速度上有现实潜力超过人类遥控手(人类缺第一视角、缺轮胎极限感知)。这是最稳的取胜赛制。
