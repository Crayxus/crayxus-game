TRACK STANDARD · AI·GP 标准赛道

赛事标准赛道规格

作为 AI·GP 规则制定方,赛道标准取自 F1TENTH / DeepRacer 国际依据,平衡竞速观赏 + 动捕成本 + 场馆可复制 + 安全。

参数标准值依据
总占地(推荐)18×10 m性价比拐点;范围 16×8(起步)~ 20×12(旗舰),介于 DeepRacer 与 F1TENTH(28.5×11)之间
赛道宽度0.9–1.1 m≈4–5 车宽,对标 F1TENTH 90cm 超车线 + 无墙容错
中线周长45–55 m够单圈计时,也够多车超车
最长直道14–16 m拉得开极速差,提升观赏
最小弯径≥0.8 mDeepRacer 工程下限之上加余量
边界涂装路肩 + 软缘石无硬墙、安全;对动捕无遮挡
赛制计时 → 头对头照搬 F1TENTH 演进:先单圈计时(AI 占优)→ 后多车贴身
💡 16×8(中天现有)可直接作起步标准:适合训练 + 单圈计时,动捕最省(8–12 台相机)。若把"多车贴身竞速"做成招牌,标准定 18×10 最划算——观赏逼近 F1TENTH,动捕只多约 50%(12–18 台)。超过 20×12 后动捕成本陡增,不建议作标准。

🎒 学生自己买(归学生)

  • 室内 AI 赛车套装 ¥9,800:Jetson + 摄像头 + LiDAR + 底盘 + 电池等,一年都用、带得走
  • 个人耗材(备用电池、反光标记球等)少量
  • (可选)室外 F1 升级,想要自己的竞技车再加

🏟️ 机构先垫资 → 分摊收回

  • NOKOV 动捕 ¥20–40 万(按一届 10 人分摊,第一届即回本)
  • 室外 RTK 基站、起跑线计时门、立体地标、锥桶
  • 训练 GPU 工作站 / 云算力、共享 F1 车队
  • 赛道用中天 16×8(起步)/ 18×10(标准场)
✅ 为什么这条路"能实现"(不是画饼)
  • 每一步都对齐已验证硬件:感知/训练/赛车线/控制全用 F1TENTH 开源生态(ROS2 + f1tenth_gym + SB3),不自研底座。
  • 击败人类有业界先例:苏黎世无人机 25:15 胜人类世界冠军;A2RL 全尺寸 AI 一年内从落后 ~10 秒/圈 → 单圈反超前 F1 车手 1.58 秒。
  • 选最稳的赛制:先打单圈计时赛(AI 跑线一致、零疲劳、毫秒反应,占优),多车贴身对决作为后期进阶。
  • turnkey 兜底:平台扛 90% 底层,学生用 vibe coding 做有意义的真活——成果真实、可答辩、撑得起证书与推荐。
