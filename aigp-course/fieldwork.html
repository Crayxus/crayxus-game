GPIO 5→ DRV8833 AIN2
GPIO 6→ DRV8833 BIN1(右电机)

GND→ 电池− 和 ESP32 GND 共地
OA1/OA2 OB1/OB2→ 左/右 N20 两根线

3通信 + 架空测试(轮子离地!)
浏览器打开: http://<IP>/tm ← 返回 JSON = 通了 http://<IP>/move?dir=F&t=300&pwm=500 ← 双轮正转 http://<IP>/move?dir=R&t=300&pwm=500 ← 左正右反 http://<IP>/stop
  • F 时两轮都朝"前"转才算对,方向不对看速查表
4落地标定(2 个数)
  • 直线速度:地上贴 1m 胶带,发 /move?dir=F&t=5000&pwm=600,量实走毫米数 ÷5 = MM_PER_S
  • 转弯:发 /move?dir=R&t=4000&pwm=600,目测转了几度 → TURN90_MS = 4000 × 90 ÷ 实际度数
  • 把两个数填进 sweeper_demo.py 顶部 CALIB
5覆盖 Demo + 录视频
